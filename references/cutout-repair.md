# 切图修整

由 agent 对照原稿决定修整和模式，不把算法、容差或候选选择交给用户。保留原始生成图，从原稿重新切图；不要反复处理已经缩放的交付 PNG。自动 QA 只能定位疑点，不能决定灰色究竟是背景还是图案。

## 复核顺序

1. 读取 `qa/report.json`，逐格比较 `source.png`、`cutout.png`、`cleaned.png`，再检查洋红、浅色和深色底上的最终图。需要判断细小部件时，按报告的 `source_bounds` 从原稿取原尺寸裁切；预览拼图的缩略图不足以验收细节。
2. **外部灰边**：确认是残底后，逐格增大外部去背容差，用能清除残留的最小值。`--background-tolerance N` 是整张图的覆盖值，`--repairs` 可只改有问题的格子。不要把个案使用的 32 当成默认值；过宽会误删与外部相连的灰色主体。
3. **封闭残底**：确认是图案间的空隙后，选该区域内的种子点与尽量紧的矩形，通过 `erase_regions` 清除。它只删除矩形内、与种子四邻域连通且接近实测背景色的像素，不处理同格其他封闭区域。若矩形截断了残留，应调整范围后重新复核，不能直接交付。
4. **rembg 误删**：比较模型结果、原稿和色彩候选。`qa/colour-candidate.png` 保留同格布局；rembg 格子的 `qa/colour-candidates/NN.png` 为原裁切尺寸透明候选。确认色彩方案更完整后，用该格的 `mode: "floodfill"` 重新切图，并继续处理残底；不要直接交付尚未归一化的候选。背景不可信时，候选也只是诊断材料，不自动判优。
5. 重新读取报告并复核**所有最终图标**。`candidate_disagreement` 表示两种方法保留的像素不同，不等同于确定的误删。`possible_cutout_loss` 也可能包含主动去掉的灰边；核对源图和修整记录，不能以提示数量少作为选图标准。仍无法可靠区分的区域需重新生成，不宣称验收通过。

## 参数与修整文件

| 参数 | 作用 |
| --- | --- |
| `--thresh N` | 边缘前景对比度和 QA 颜色相似度，默认 24；不会提高背景删除容差 |
| `--background-tolerance N` | 与裁切边界连通的背景色差上限，0–255；默认使用采样噪声容差 |
| `--repairs /absolute/task/repairs.json` | 逐格覆盖模式、外部容差，或指定局部背景清除 |

色差按 RGB 三个通道的最大绝对差计算。外部容差不改变报告里的背景采样噪声。封闭区域的近乎精确匹配规则会排除与外部连通的采样噪声区域，避免绕过较小的外部容差；设为 0 时不会因“封闭区域”规则删除色差为 1 的外部部件。使用 rembg 的格子，其外部容差只作用于色彩候选。

`repairs.json` 示例（坐标仅用于说明，必须替换为实际裁切坐标）：

```json
{
  "cells": {
    "3": {
      "mode": "floodfill",
      "background_tolerance": 16
    },
    "12": {
      "erase_regions": [
        {
          "seed": [110, 130],
          "bounds": [100, 120, 125, 150],
          "tolerance": 4
        }
      ]
    }
  }
}
```

- `cells` 的键是从 1 开始的行优先格号，只能指定本次导出的格子；不要使用前导零。
- 每格三个字段都可省略。`mode` 为 `floodfill` 或 `rembg`，优先于风格模式和自动回退。外部容差优先级为该格覆盖 → 命令行覆盖 → 采样噪声。
- `seed: [x, y]` 和 `bounds: [left, top, right, bottom]` 相对报告 `source_bounds` 对应的**外扩原尺寸裁切**，不是原图全局坐标或 512px 成品坐标。右、下边界不包含；种子和矩形必须位于该格的 `owned_bounds` 内。
- 每个局部区域必须完整指定种子、范围和 0–255 的整数容差；种子须匹配实测背景。模式错误、范围越界、无效种子，以及任意层级的重复 JSON 键（包括重复格号）均在导出前报错，已有输出不变。同一格的修整应合并到一个对象内。
- 局部修整在边缘处理之后、清理和缩放之前执行，也用于该格的色彩候选。清除后不重新推断边缘，避免把选区外原本不透明的浅色图案改成半透明。`applied_repairs` 记录选中模式下每次实际删除的像素数；0 表示选区本已透明或没有可删像素，不能仅凭命令成功就认为问题解决。

```bash
"$SKILL_DIR/.venv/bin/python" "$SKILL_DIR/scripts/slice_icons.py" \
  "/absolute/task/raw/style.png" "/absolute/task/out" \
  --mode rembg --grid 4 --repairs "/absolute/task/repairs.json"
```

沿用首次切图的 `--grid`、`--count`、`--size` 和风格参数。报告中每格的 `mode` 表示实际使用的方法；全局 `effective_mode: "mixed"` 表示逐格采用不同方法。候选预览含所有导出格，非 rembg 格显示当前清理结果；以本次报告中列出的候选路径为准。
